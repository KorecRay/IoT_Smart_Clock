# 智能動態鬧鐘專案

一個結合個人化行事曆、即時天氣、交通時程分析與實體行為認證的物聯網（IoT）智能鬧鐘系統。

---

## 🔒 版本控制規範

為確保 `main` 主幹程式碼的穩定性與部署品質，本儲存庫已啟用 **Branch Protection Rules**

### 1. DO NOT直接提交主幹
* **`main` 分支保護**：嚴禁任何成員直接執行 `git push origin main`。
* 任何直接對 `main` 分支進行 Push 的操作均會被退回。

### 2. 強制 Pull Request 流程
* 所有新功能開發（Features）、系統修復（Fixes）或文件更新，**必須** 自 `main` 切出獨立分支進行。
* 開發完成後，必須將分支推至遠端並發起 **PR**。

### 3. 強制 Code Review 
* 每個 PR 在合併前，**必須取得至少 1 位團隊成員的 Approve**。
* 未經審核認可之 PR 將被拒絕合併至主幹。
